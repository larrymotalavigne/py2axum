# Advanced

These pages go beyond the tutorial: [How it works](how-it-works.md) follows a route through the compiler and
the runtime; [Graceful shutdown](shutdown.md), [Large list responses](streaming.md), [Sentry](sentry.md),
[Prometheus metrics](metrics.md) and [MCP servers](mcp.md) describe runtime features in detail;
[Performance](performance.md) gives the measured numbers and how to reproduce them;
[Conformance and replay](conformance.md) shows how to check that the binary answers like your application;
[Docker image](docker.md) builds the binary without installing anything; [Deployment](deployment.md)
covers Docker, Kubernetes and the hybrid setup; and
[Security](security.md) describes what the generated server guarantees in front of untrusted clients.
