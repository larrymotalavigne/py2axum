# Libraries

Third-party libraries are translated through a closed map: the calls listed here are reproduced by the runtime,
and any other call of a library is refused at compile time with `file:line` (leave the route to Python with
`--python-side`, see [Hybrid mode](../getting-started/hybrid.md)).

Arguments follow the same rule: one the runtime does not implement is refused (at compile time when the call can be recognized there, else with a `TypeError`), never ignored. The exceptions are network settings that cannot change a response, only when a failure happens: httpx `Timeout(write=, pool=)`, aiohttp `ClientTimeout(ceil_threshold=)`, aio-pika `connect(timeout=)`, `publish(mandatory=, immediate=, timeout=)` and `channel(publisher_confirms=)` (the binary always waits for the broker's confirmation).

## File formats left to Python

Libraries that write a file are translated only when their output is reproducible byte for byte. `fpdf2`
(the PDF carries its creation date), `python-docx` and `openpyxl` (the zip entries carry the time they were
written), `reportlab`, `weasyprint`, and the readers `xlrd`, `olefile`, `pdfplumber` stay in Python: declare
the routes `--python-side auto` ([Hybrid mode](../getting-started/hybrid.md)).
